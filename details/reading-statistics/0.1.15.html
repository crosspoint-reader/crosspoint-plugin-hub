Reading Statistics

Reading Statistics (Dessen App) for current Razor-Crest firmware, with optional Techy-Notes sync and a native SD dashboard fallback.

Explore global and individual-book reading time, counted sessions, qualified page turns, time-of-day patterns, a seven-day chart, and a numbered monthly Reading Calendar with Best Day, Daily Average, and Reading Consistency insights.

The sixth page can preview and import existing CrossInk and vCodex reading history into the firmware's native binary records. Import requires a second confirmation, preserves source files, and uses durable receipts to prevent duplicate imports.

Compatibility: Plugin Hub requires stats.native.v1 and ui.dashboard.v2. Stock CrossPoint is excluded from discovery starting with v0.1.14 until the necessary upstream support is available. No KOSync configuration or Techy-Notes account is required. Local statistics remain offline. A durable pairing credential outside the installed plugin folder survives uninstall/reinstall. Server sync is opt-in and targets the production Techy-Notes server. Dessen mode on updated Razor-Crest supports batched cumulative history upload and refresh, with declarative event synchronization reserved for fallback mode.
