Sort EPUBs by Author

Organize EPUB books in the current folder into subfolders named after each book's author, using the reader's browser-based File Manager.

Reads author metadata from the EPUB; skips books with missing author information and leaves non-EPUB files untouched. When present, accompanying .key and .rights files move with the book.

Runs only on the selected folder, not recursively. Review your folder before organizing because this operation moves files.
