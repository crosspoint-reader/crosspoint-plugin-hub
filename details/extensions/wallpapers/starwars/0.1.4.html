Star Wars & The Mandalorian Wallpaper Collection

A collection of 19 monochrome Star Wars and Mandalorian-inspired sleep wallpapers, tailored to CrossPoint e-readers.

Included

  • 19 distinct sleep-screen images in each display-size package
  • Carefully cropped artwork without white borders
  • Four-level grayscale, dithered for e-ink displays
  • Two separately installable, screen-specific packages

Choose your device size

  • 528 × 792 pixels: Star Wars (528x792), package starwars-x3
  • 480 × 800 pixels: Star Wars (480x800), package starwars-x4plus

Plugin Hub automatically selects the correct resolution when the firmware supports this collection. Only one matching variant should be installed on each device.

Installation and compatibility

Requires firmware advertising wallpaper.packs.v1. Stock CrossPoint builds without this capability cannot install or use standalone wallpaper packs.

After installation, choose Settings → Display → Sleep Screen → Custom, then select the Star Wars collection from Wallpaper Collection.

This collection changes sleep-screen artwork only. It does not replace themes, reader fonts, books, or plugins.
