HALO — CrossPoint Theme

A monochrome HALO-inspired interface with custom e-ink artwork, Chakra Petch fonts, and three rotating sleep scenes.

Appearance

  • HALO-inspired Home and Settings presentation
  • UNSC-style headers, emblem artwork, and chamfered interface elements
  • Four Chakra Petch interface font slots
  • Three themed sleep images selected at random
  • Graphic-only HALO USB Drive screen, painted before SD handoff
  • Theme preferences for supported navigation layouts

Compatibility

Requires firmware advertising the theme capabilities declared in this package's manifest. Stock CrossPoint releases without those capabilities are not supported. Compatibility is capability-based, not tied to a hard-coded firmware name.

Installation

Open the Theme entry in Plugin Hub, review its details, then select Install on compatible firmware. For manual installation, place the complete halo.crosspoint-theme folder in /.crosspoint/themes/ and select HALO under Settings → Display → UI Theme.
