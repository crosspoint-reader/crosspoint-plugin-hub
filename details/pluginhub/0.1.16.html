Plugin Hub

Discover, install, and update plugins from the reader without manually copying plugin files to the SD card.

Features

  • Browse the Community plugin catalog and any future dynamic catalog lists.
  • Install complete multi-file plugin bundles from catalog entries.
  • Detect installed versions and show available updates without offering downgrades.
  • Follow dynamic catalog lists so catalog organization can change without a Plugin Hub release.
  • Respect firmware family, plugin API, and capability requirements declared by plugins.

Requirements

  • The firmware plugin system must be enabled.
  • Wi-Fi is required to refresh catalogs or install and update plugins.

Notes

All currently published plugins appear in Community Plugins and are not vetted by the firmware development team. Plugin Hub uses generic firmware plugin-system capabilities that are available to other plugins as well.
